# ExpenseTracker - Quantum Midnight Edition

A high-performance, visually stunning Android expense tracking application built with Jetpack Compose. This app features a "Quantum Midnight" aesthetic, focusing on fluid animations, glass-morphism, and a premium user experience.

## ✨ Features

- **Quantum Midnight UI**: A dark-themed, modern interface with neon accents and interactive animations.
- **Smart Dashboard**:
    - Dynamic greetings based on the time of day.
    - Integrated "Spend Dynamics" line chart for visual financial trends.
    - Functional category filters (Food, Transport, Travel, etc.) with instant list updates.
- **Dynamic Profile Management**:
    - Personalized "Commander Profile" with an editable user name.
    - Real-time synchronization of user data across the UI.
- **Comprehensive Expense Entry**:
    - Decimal-optimized numeric keypad for amount entry.
    - Integrated Date Picker for logging past or future transactions.
    - Flexible category selection and optional detailed notes.
- **Financial Analytics**:
    - Detailed asset allocation breakdown with column charts.
    - Progress-tracked category matrix showing percentage-based spending.
- **Budgeting & Alerts**:
    - Set daily, weekly, or monthly budgets.
    - Interactive "Pulse" progress bars with visual warnings when nearing limits.
- **Data Portability**:
    - One-click CSV export with Android Share Sheet integration for easy reporting.

## 🛠 Tech Stack

- **UI**: Jetpack Compose (100% Kotlin)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Database**: Room Persistence Library
- **Navigation**: Compose Navigation
- **Charts**: Vico Charts
- **Persistence**: SharedPreferences (for user settings)
- **Concurrency**: Kotlin Coroutines & Flow

## 🚀 Getting Started

### Prerequisites
- Android Studio Iguana or newer
- JDK 17+
- Android SDK Level 24 (Nougat) or higher

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Lakshya-Asati/Expense-Tracker-App.git
   ```
2. Open the project in **Android Studio**.
3. Let Gradle sync and download dependencies.
4. Run the app on an emulator or physical device.
